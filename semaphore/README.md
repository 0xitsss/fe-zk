# fe_zk_semaphore

Semaphore v4 proof verification for Fe contracts. Proofs are made with Semaphore's own JS SDK
(`@semaphore-protocol/proof`), keys are the published keys of the Semaphore trusted-setup ceremony.

```fe
use fe_zk_semaphore::verify_proof_low

// scope: fixed at deploy; message: what the member commits to (vote option, recipient, signal hash)
let ok = verify_proof_low(depth, root, nullifier, message, scope, points)   // uses (call, ctx)
```

| function | depths | code size |
| --- | --- | --- |
| `verify_proof(depth, root, nullifier, message, scope, points)` | 1..10 | about 11 KB |
| `verify_proof_low(...)` | 1..5 (groups up to 32) | about 7 KB |
| `verify_proof_high(...)` | 6..10 | about 7 KB |
| `key_digest(depth)` | 1..10 | tiny; digest of the key as emitted by `fe-zk-gen` |

All return `false`, never revert, for a depth outside their range, a non-canonical word, or a proof
that does not verify. The arguments are the fields of Semaphore's `SemaphoreProof`
(`merkleTreeDepth, merkleTreeRoot, nullifier, message, scope, points[8]`).

* Public inputs: `[root, nullifier, hash(message), hash(scope)]`, `hash(x) = keccak256(x) >> 8`
  (same as `Semaphore.sol`).
* `points` is Semaphore's packed proof `[a0, a1, b01, b00, b11, b10, c0, c1]`, B in EVM order, as
  `SemaphoreVerifier.verifyProof` takes it.
* The caller still has to check that `root` is a root of its group (`fe_zk::anon::LeanImt::is_known_root`)
  and to spend the nullifier per scope (`fe_zk::anon::Nullifiers`), see `examples/anon_*`.
* Gas: about 216k for one verification (any depth).
* Code size: a contract with a `LeanImt` (about 14 KB) plus `verify_proof` (about 11 KB) does not
  fit the 24,576-byte limit; the examples use `verify_proof_low` (depth <= 5) and cap the group at 32
  members. For larger groups keep the tree and the verifier in two contracts.

Tests (`fe test` in this directory, about 3 minutes of key compile time): the real ceremony proof of
`vectors/groth16/real_semaphore_d10`, one SDK proof per depth 1..10, wrong or out-of-range depth,
tampered message / scope / nullifier / root / every proof word, non-canonical words, B word order.
`scripts/check-semaphore-sol.sh` checks the same proofs against Semaphore's own `SemaphoreVerifier.sol`.

Keys: `src/keys_d<k>.fe` are generated by `scripts/regen-semaphore-keys.sh` (fe-zk-gen `--lib-module`
from `packages/proof/src/verification-keys.json` at semaphore-protocol commit `dbab5553`, sha256
pinned); `src/lib.fe` by `scripts/gen-semaphore-lib.py`; `src/tests.fe` by `scripts/gen-semaphore-tests.py`.
Every key point is checked at compile time (on curve, G2 in the subgroup, not infinity).
